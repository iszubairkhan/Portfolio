# 🚀 Personal Developer Portfolio

A sleek, responsive, and minimalist developer portfolio website showcasing my technical toolkit, featured projects, and contact info. Built with a modern terminal aesthetic and optimized for fast performance and low latency.

---

## 🛠️ Built With

* **HTML5 & CSS3** – Clean semantic structure and responsive layout
* **Tailwind CSS (via CDN)** – Modern utility-first styling with dark-mode aesthetic
* **Lucide Icons** – Lightweight, scalable vector iconography
* **Fira Code & Inter Fonts** – Developer-first typography via Google Fonts
* **GitHub Pages** – Automated hosting and continuous deployment
